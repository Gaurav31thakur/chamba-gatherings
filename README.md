# Maharana's Hearth

Build a completely new website from scratch for **Maharana Pratap Bhawan**, located in **Adarsh Nagar, Hardaspura, Chamba, Himachal Pradesh**.

Use:

* Next.js
* TypeScript
* Tailwind CSS
* App Router
* MongoDB
* Prisma ORM with MongoDB
* Reusable components
* Responsive design

This is a fresh project.

Do not assume any existing codebase, layout, design system, or previous website structure.

Create the architecture, visual identity, components, pages, database models, forms, and admin dashboard from scratch.

# BUSINESS

Maharana Pratap Bhawan has two main offerings:

## 1. Event Halls

The property hosts:

* Weddings
* Birthday parties
* Retirement parties
* Dham
* Family functions
* Celebrations
* Gatherings

Hall bookings are enquiry-based.

Visitors should not directly book a hall online.

## 2. Homestay

The property also has:

**6 registered homestay rooms**

Visitors should be able to:

* explore rooms
* view room details
* check room information
* choose stay dates
* send/book a room request
* see estimated price
* receive a booking reference

The website should represent BOTH offerings equally.

The homestay must not feel like a small secondary feature.

# CORE POSITIONING

The main idea of the website should be:

# Celebrate. Stay. Make Memories.

Visitors should immediately understand:

**Maharana Pratap Bhawan is a place where families can celebrate an occasion and also stay comfortably at the same property.**

This connection between events and homestay should be visible throughout the website.
